# Masti 🎮

A beginner-friendly Java console game: **Guess the Number**.

The computer chooses a random number from 1 to 100. Keep guessing, and the game tells you whether your guess is too high or too low.

## Run online (no installation)

1. Open [Replit](https://replit.com/).
2. Sign in, then choose the option to import a project from GitHub.
3. Paste this repository URL: https://github.com/Akhilesh-0205/Masti
4. Select **Java** if Replit asks for a language or template.
5. Open `Main.java` and click **Run**. Enter your guesses in the console.

If GitHub import is unavailable in your Replit account, create a new Java project there and copy the contents of `Main.java` into its `Main.java` file.

## Run with Java locally

If Java is installed, open a terminal in the project folder and run:

```bash
javac Main.java
java Main
```

## What this project practices

- Variables and data types
- `Scanner` for keyboard input
- `Random` for generating a secret number
- `if/else` conditions
- `while` loops
- Basic input validation
